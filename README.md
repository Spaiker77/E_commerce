# Магазин электроники и товаров для сада

## Функциональность

### Основные классы
1. **`BaseProduct`** (абстрактный класс):
   - Определяет общий интерфейс для всех продуктов
   - Обязательные методы: `__init__`, `__str__`, `__add__`

2. **`Product`** (базовый класс товара):
   - Наследует `BaseProduct`
   - Добавляет миксин `LoggingMixin` для логирования

3. **Наследники**:
   - **`Smartphone`**: Смартфоны с доп. атрибутами 
   - **`LawnGrass`**: Газонная трава с характеристиками

4. **`Category`**:
   - Управление категориями товаров
   - Автоматический подсчет продуктов

5. **`Order`** (доп. задание):
   - Оформление заказов
   - Контроль остатков товаров
