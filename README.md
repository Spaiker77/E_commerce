# Каталог продукции

## Функционал

- Класс Product с атрибутами:
  - Название товара
  - Описание
  - Цена
  - Количество на складе
  
- Класс Category с:
  - Название категории
  - Описание
  - Список товаров
  - Автоматический подсчет категорий
  - Автоматический подсчет уникальных товаров

- Тестирование:
  - Проверка создания объектов
  - Проверка подсчетов
  - Покрытие тестами >75%
